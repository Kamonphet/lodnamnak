# Lodnamnak

เว็บแอปดูแลสุขภาพ ควบคุมน้ำหนัก โภชนาการ และตารางออกกำลังกายรายสัปดาห์ พร้อมโมเดลร่างกาย 3 มิติแบบเรียลไทม์ รองรับการติดตั้งบนหน้าจอมือถือ (PWA)

## ฟีเจอร์หลัก
- **วิเคราะห์สุขภาพรายบุคคล**: คำนวณ BMI, BMR, TDEE, งบแคลอรี และโปรตีนตามเพศ อายุ ส่วนสูง น้ำหนัก และกิจกรรมจริง
- **หุ่นจำลอง 3 มิติ (`Three.js`)**: หมุนอัตโนมัติ 360° ปรับสัดส่วนตามข้อมูลจริง เปรียบเทียบรูปร่างเป้าหมาย และแสดงท่าออกกำลังกาย
- **ติดตามมื้ออาหาร & วิเคราะห์พฤติกรรม**: ประเมินพลังงาน/สารอาหารจากเมนูอาหารภาษาธรรมชาติ หรือกรอกค่าจากฉลากโภชนาการเอง
- **ตารางออกกำลังกายรายสัปดาห์**: คำนวณพลังงานเผาผลาญตามน้ำหนักตัว (METs) และจัดตาราง 7 วันตามเวลาว่าง
- **ระบบความปลอดภัยด้านสุขภาพ**: แจ้งเตือนเมื่อเป้าหมายต่ำกว่า 1,200 kcal/วัน, ค่า BMI ต่ำกว่าเกณฑ์ หรือวิธีลดน้ำหนักที่เป็นอันตราย
- **รองรับผู้ใช้งานหลายคน**: สลับโปรไฟล์ในเครื่องเดียว และส่งออก/นำเข้าข้อมูลเป็นไฟล์ `.json`

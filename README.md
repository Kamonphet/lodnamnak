# Lodnamnak (ลดน้ำหนัก)

เว็บแอปพลิเคชัน Mobile-first PWA Health Coach & Weight Management ดูแลสุขภาพ ควบคุมน้ำหนัก โภชนาการ และการออกกำลังกาย พร้อมโมเดลร่างกาย 3 มิติแบบเรียลไทม์ (`Three.js`), ระบบจัดจานอาหารเฉพาะมื้อ, ระบบถ่ายภาพฉลากโภชนาการและส่วนประกอบ (OCR & Decision Engine), และระบบ Gamification สไตล์ Modern Pastel Bento

---

## ฟีเจอร์หลัก (Key Features)

### 1. โมเดลร่างกาย 3 มิติแบบเรียลไทม์ (Interactive 3D Body Avatar)
- สร้างและเรนเดอร์ด้วย **Three.js** หมุนได้ 360 องศา พร้อมรองรับการใช้นิ้วลากหมุนอย่างอิสระ
- สัดส่วนร่างกาย (รอบเอว, สะโพก, หน้าท้อง, ไหล่, ความหนาแขนขา) ปรับตาม **BMI จริง + เพศ + มวลกล้ามเนื้อ**
- **สไลเดอร์เปรียบเทียบรูปร่าง (Target Morph Slider)**: เลื่อนดูความเปลี่ยนแปลงระหว่างรูปร่างปัจจุบันและรูปร่างเป้าหมาย
- แอนิเมชันท่าออกกำลังกายเสมือนจริง: เดิน/วิ่ง, เวทเทรนนิ่ง/ดัมเบล, มวยไทย, โยคะ, และกีฬาพร้อมลูกบอล
- สวมใส่ไอเทมรางวัล 3D ที่ปลดล็อกได้จริงบนตัวละคร: **คาดหัวทอง (Gold Headband)**, **ออร่ามรกต (Emerald Aura)**, และ **มงกุฎแชมเปี้ยน (Champion Crown)**

### 2. ผู้ออกแบบมื้ออาหาร & ภาพจานสัดส่วนจริง (Per-Meal Nutrition & Visual Plate Designer)
- **จัดสรรงบพลังงานและโปรตีนเฉพาะมื้อ**: แบ่งตามรูปแบบมื้อที่เลือก (เช่น 3 มื้อมาตรฐาน, 3 มื้อ + ของว่าง, IF 2 มื้อ, 4 มื้อสร้างกล้ามเนื้อ)
- **ภาพจานจำลองสัดส่วนจริง (Visual Plate SVG)**: แสดงภาพจานอาหารแบ่งช่องผักครึ่งจาน โปรตีน คาร์บ และท็อปปิ้ง (อกไก่, ปลา/แซลมอน, เต้าหู้, ไข่ต้ม) เปลี่ยนแปลงตามที่เลือกแบบเรียลไทม์
- **จัดจานเอง (Custom Plate Builder)**: เลือกสัดส่วนคาร์บ (0–2 เท่า), แหล่งโปรตีน, ผักเคียง, วิธีปรุง (ต้ม/นึ่ง/ย่าง, ผัดน้ำมันน้อย, ผัดปกติ) และของเสริมพิเศษ พร้อมคำนวณแคลอรีและสารอาหารทันที
- **สลับเมนูทางเลือก**: สุ่มเมนูอาหารเพื่อสุขภาพที่เข้ากันได้ตามงบมื้อนั้นๆ และสอดคล้องกับข้อจำกัดทางอาหาร (เช่น มังสวิรัติ, ฮาลาล, วีแกน, แพ้อาหาร)

### 3. ระบบถ่ายภาพฉลากโภชนาการและส่วนประกอบ (Nutrition Label OCR & Decision Engine)
- **ถ่ายภาพหรืออัปโหลดภาพฉลาก (Label Photo Capture)**: รองรับทั้งเปิดกล้องหลังมือถือถ่ายภาพสดโดยตรง (พร้อมกรอบช่วยเล็ง) และเลือกรูปภาพฉลากจากคลังภาพ
- **อ่านข้อความและสกัดตัวเลขอัตโนมัติ (Client-side Tesseract.js OCR)**: สกัดพลังงาน (kcal), โปรตีน, คาร์โบไฮเดรต, ไขมัน, น้ำตาล, โซเดียม, หน่วยบริโภค และรายการส่วนประกอบสำคัญ ทำงานบนเครื่องผู้ใช้ 100% ปลอดภัยและเป็นส่วนตัวสูง
- **ระบบช่วยตัดสินใจและเตือนสารก่อภูมิแพ้ (Decision Engine)**: ตรวจจับสารก่อภูมิแพ้ (นม, ไข่, ถั่ว, กลูเตน, อาหารทะเล, หมู ฯลฯ) เทียบกับข้อจำกัดทางอาหารของผู้ใช้ พร้อมคำนวณผลกระทบต่อโควตาพลังงานที่เหลือของวัน และแนะนำสัดส่วนที่ควรทาน
- **หน้าจอตรวจสอบและปรับแต่ง (Interactive Review Screen)**: แสดงภาพตัวอย่างที่ถ่าย พร้อมช่องตัวเลขให้ผู้ใช้ตรวจสอบหรือปรับแก้ก่อนกดยืนยันบันทึก

### 4. ระบบกระตุ้นการใช้งานรายวัน (Daily Gamification & Safe Quests)
- **สถิติไฟต่อเนื่อง (Daily Streak)**: นับวันใช้งานต่อเนื่องจากมื้ออาหาร, การออกกำลังกาย, น้ำดื่ม หรือการชั่งน้ำหนัก
- **เกราะคุ้มกันสถิติอัตโนมัติ (Weekly Streak Shield `เกราะ x1`)**: ให้อภัยการขาดใช้งาน 1 วันต่อสัปดาห์โดยไม่ตัดไฟต่อเนื่อง
- **ตารางเช็กอิน 7 วันย้อนหลัง**: จุดแสดงสถานะเช็กอิน (จ.–อา.)
- **4 ภารกิจรายวันพร้อมโบนัส All-Clear (+20 XP)**:
  1. บันทึกมื้ออาหารวันนี้ (`+20 XP`)
  2. ออกกำลังกาย หรือ ดื่มน้ำครบ 8 แก้ว (`+25 XP`)
  3. โปรตีนถึงเกณฑ์ดูแลกล้ามเนื้อ (`+30 XP`)
  4. สมดุลพลังงานปลอดภัย (`+35 XP`): *มีระบบ Health Safety Guardrail บล็อกไม่ให้ผ่านหากทานต่ำกว่า 1,200 kcal/วัน ป้องกันการอดอาหารอันตราย*
- **เหรียญความสำเร็จ 18 เหรียญ (Achievement Badges)**: แบ่งเป็น 4 ระดับ (ง่าย, ปานกลาง, ท้าทาย, ตำนาน) พร้อมระบบกรองดูเหรียญ
- **ระดับเลเวลและฉายา (Level & Rank Titles)**: สะสม XP เลเวลละ 150 XP ไต่ระดับสู่ "แชมเปี้ยนสุขภาพยั่งยืน"

### 5. แอนิเมชันแก้วน้ำกำลังเติมน้ำ (Interactive Water Glass Wave)
- แก้วน้ำ SVG ทรงมนสีฟ้าใส ระดับน้ำจะค่อยๆ ไหลสูงขึ้นตามจำนวนแก้วจริง (0–8 แก้ว)
- แอนิเมชัน **คลื่นน้ำพริ้ว 2 ชั้น (Double Liquid Waves) + ฟองอากาศลอยขึ้น**
- แถวหยดน้ำ 8 ดวงข้างแก้ว แสดงสัดส่วนเป้าหมายและขึ้นเครื่องหมายสำเร็จเมื่อครบเกณฑ์

### 6. ประวัติและพัฒนาการย้อนหลัง (Progress & Historical Timeline)
- **กราฟแนวโน้มน้ำหนัก (SVG Trend Chart)**: กราฟเส้นแนวโน้มการเปลี่ยนแปลงน้ำหนัก พร้อมจุดบันทึก Check-in ที่กดดูน้ำหนักและวันที่บันทึกได้
- **การ์ดสรุปพัฒนาการภาพรวม**: แสดงน้ำหนักเริ่มต้น, น้ำหนักปัจจุบัน, น้ำหนักเป้าหมาย, น้ำหนักที่เปลี่ยนแปลงไป, และร้อยละความสำเร็จสู่เป้าหมาย
- **ไทม์ไลน์ประวัติรายวัน (Daily History Timeline)**: เก็บบันทึกย้อนหลังแยกรายวัน แสดงแคลอรีที่ทาน/เป้าหมาย, แคลอรีที่เผาผลาญ, แก้วน้ำดื่ม, สารอาหารหลัก (โปรตีน/คาร์บ/ไขมัน), และจำนวนรายการอาหาร/กิจกรรมในแต่ละวัน

### 7. ระบบตัดรอบวันตามเวลาท้องถิ่น & จดจำตารางออกกำลังกาย (Smart Date & Workout Persistence)
- **Local Midnight Cut-off**: คำนวณวันที่ตามเวลาท้องถิ่นของผู้ใช้ (`getLocalDateKey`) ตัดรอบวันใหม่ทันทีเมื่อพ้น 00:00 น. ไม่ดีเลย์ 7 ชั่วโมงจากปัญหา Timezone UTC และโยกข้อมูลวันก่อนหน้าเข้าสู่ประวัติย้อนหลังอัตโนมัติ
- **Persistent Workout Checklist**: จดจำการติ๊กวันออกกำลังกายประจำสัปดาห์ลง `localStorage` ทันที ไม่สูญหายเมื่อสลับแท็บหรือรีเฟรช พร้อมตรวจจับรอบสัปดาห์อัตโนมัติเพื่อรีเซ็ตรอบใหม่เมื่อถึงสัปดาห์ถัดไป

### 8. หน้าแรกสไตล์ Modern Pastel Bento & Visual Dashboards
- **แถบสลับ 4 หมวดย่อยใต้หุ่น 3D**:
  - **วันนี้**: วงแหวนเกจแคลอรีทรงกลม (Calorie Ring Gauge), หลอดโปรตีนพร้อมไอคอน, แก้วน้ำเติมน้ำไว, และเส้นทางน้ำหนัก (Weight Journey Bar)
  - **พัฒนาการ**: กราฟน้ำหนักแนวโน้ม และไทม์ไลน์ประวัติย้อนหลังรายวัน
  - **ภารกิจ**: เลเวล, ไฟต่อเนื่อง, เกราะคุ้มกัน, และรายการภารกิจ 4 ข้อ
  - **แผน & เผาผลาญ**: ค่า BMI, BMR, TDEE และตัวเลือกจังหวะสู่เป้าหมาย
- **ระบบหลายบัญชีในเครื่องเดียว (Multi-Profile Local Persistence)**: บันทึกข้อมูลแยกอิสระใน `localStorage` รองรับการนำเข้า/ส่งออกเป็นไฟล์ JSON พร้อมระบบ Sanitize ป้องกัน Prototype Pollution

## ความปลอดภัยของระบบ (Security & Privacy)

- **Content Security Policy (CSP)**: บังคับใช้นโยบาย CSP เคร่งครัดในระดับ Production HTML meta tag
- **Safe JSON Import Parsing**: กรองคีย์อันตราย (`__proto__`, `constructor`, `prototype`) ป้องกัน Prototype Pollution
- **Client-Side First & Data Privacy**: ข้อมูลสุขภาพทั้งหมดถูกประมวลผลและจัดเก็บบนเครื่องผู้ใช้ ไม่มีการส่งข้อมูลส่วนบุคคลไปยังเซิร์ฟเวอร์ภายนอก
- **Health Safety Floor**: ล็อกเกณฑ์ความปลอดภัยพลังงานขั้นต่ำ 1,200 kcal/วัน และแจ้งเตือนทันทีหากอัตราการลดน้ำหนักสูงเกินเกณฑ์ปลอดภัย

## การติดตั้งและใช้งานในเครื่อง (Local Setup)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันโหมด Development (Vite Dev Server)
npm run dev

# 3. รันการทดสอบ Unit Tests (Vitest 28 Tests ครอบคลุมคำนวณโภชนาการ ฉลาก OCR และความปลอดภัย)
npm run test

# 4. ทดสอบบิลด์ระดับ Production
npm run build
```

## เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Core**: React 19, TypeScript
- **3D Graphics**: Three.js
- **OCR Engine**: Tesseract.js (Client-side offline OCR สำหรับภาษาไทยและอังกฤษ)
- **Styling & Theme**: Tailwind CSS, Liquid Glass & Pastel Bento Design System
- **Icons**: Lucide React
- **Data Source**: Open Food Facts REST API (Thailand / World)
- **Build Tool**: Vite
- **Testing**: Vitest
